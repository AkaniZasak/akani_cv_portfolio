AKANI SUCCESS KUBAYI — CV PORTFOLIO WEBSITE

HOW TO OPEN IN VS CODE
1. Extract akani_cv_portfolio.zip to a folder.
2. Open VS Code.
3. Select File > Open Folder and choose the extracted akani_cv_portfolio folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, double-click index.html to open it in your browser.

FILES
- index.html       Home page
- about.html       About
- skills.html      Skills & Language
- projects.html    Projects
- education.html   Education and training
- experience.html  Work experience
- contact.html     Contact
- style.css        Shared styling and responsive layout
- script.js        Mobile menu, current year, contact email draft

NOTES
- All navigation buttons open separate pages.
- The language section is marked for you to complete because no languages were listed in the CV supplied.
- The contact form opens an email draft; it does not send messages to a server.
- The design imports Google Fonts, so the chosen fonts need an internet connection. It falls back to common system fonts.
- Review the spelling of employer names, contact details and dates before publishing.
